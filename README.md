# MassLab — лабораторная работа «Времяпролётный масс-спектрометр»

Настольное приложение (PySide6 + Matplotlib) для выполнения лабораторной
работы по принципу действия времяпролётного (TOF) масс-спектрометра.
Архитектура — **MVP с пассивным видом** (Model–View–Presenter, Passive View).

## Порядок работы студента

1. **Вход** — ФИО и группа (хранятся только в памяти до закрытия программы).
2. **Входной тест** — 10 случайных вопросов из банка (сейчас 30), у каждого
   4–6 вариантов ответа в случайном порядке. Зачёт — не менее **9 из 10**.
   При пересдаче выдаются другие вопросы; число попыток не ограничено.
3. **Задание 1. Запуск ионов** — студент выбирает ионы, меняет ускоряющее
   напряжение, наблюдает спектр и траектории и отвечает на 3 контрольных
   вопроса, требующих измерений на приборе.
4. **Задание 2. Неизвестный элемент** — по спектру с калибровочной смесью
   (He, Ar, Xe) нужно измерить время пролёта, вычислить массу (допуск ±2 %)
   и выбрать элемент.
5. **Задание 3. Состав сплава** — спектр сплава с реальным изотопным составом;
   нужно выбрать сплав из 5 вариантов.
6. **Итог** — время каждого этапа, число попыток, общее время и отметка «ЗАЧТЕНО».

В заданиях при неверном ответе выдаётся новое задание (вопросы или образец),
чтобы ответ нельзя было подобрать перебором.

## Конфиденциальность

Программа **ничего не записывает на диск**: нет файлов результатов, журналов
или настроек. Каждый запуск — новая сессия; данные студента исчезают при
закрытии окна или по кнопке «Новая сессия». Итог нужно показать
преподавателю на экране. Банк вопросов собирается внутрь exe и не лежит
рядом с программой отдельным файлом.

## Запуск из исходников

```bash
pip install -r requirements.txt
python main.py
```

## Сборка exe для Windows

**Вариант 1 — GitHub Actions.** При каждом push workflow
`.github/workflows/build-exe.yml` запускает тесты, собирает exe на Windows,
проверяет его запуск и выкладывает артефакт **MassLab-windows**
(вкладка *Actions* → последний запуск → *Artifacts*).

**Вариант 2 — на любом компьютере с Windows и Python 3.10+:** запустите
`build_exe.bat`. Результат — папка `dist\MassLab`.

Папку `MassLab` целиком копируют на флешку, а с неё — на компьютер в классе;
запускается `MassLab.exe`. Установка Python на компьютерах класса не нужна.

## Как добавить вопросы в тест

Откройте `masslab/model/question_bank.py` и добавьте запись в `QUESTION_BANK`:

```python
Q("Текст вопроса?",
  correct="Правильный ответ",
  wrong=("Неверный 1", "Неверный 2", "Неверный 3")),
```

Неверных вариантов — от 3 до 5. Тесты (`pytest`) проверяют формат всех
вопросов. После изменения банка exe нужно пересобрать.

## Структура проекта

```
main.py                     точка входа: создаёт вид и главный презентер
masslab/
  events.py                 Event — события видов без зависимости от Qt
  model/                    предметная логика, без Qt
    physics.py              t = L·√(m / 2qU), m по времени пролёта
    elements.py             элементы, средние массы, изотопы
    spectrum.py             построение спектра, поиск пиков
    alloys.py               сплавы и их изотопные спектры
    quiz.py                 вопросы и входной тест
    question_bank.py        банк вопросов
    tasks.py                модели заданий 1–3
    session.py              сессия студента и время этапов (в памяти)
  presenters/               вся логика интерфейса, без Qt
    app.py                  порядок этапов, таймер, итог
    login.py quiz.py demo.py element.py alloy.py report.py
    workspace.py            панель прибора (общая для заданий)
  views/
    interfaces.py           контракты пассивных видов (Protocol)
    viewmodels.py           данные для отображения (графики, отчёт)
    qt/                     реализация видов на PySide6 — без логики
tests/                      pytest: модель, презентеры с поддельными видами, Qt-виды
```

**Пассивный вид:** виды только сообщают о действиях пользователя через события
и показывают то, что им передали. Все решения принимают презентеры, которые
работают с интерфейсами из `views/interfaces.py`, поэтому они полностью
тестируются без Qt (`tests/fakes.py`).
