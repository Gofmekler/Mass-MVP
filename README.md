# MassLab — лабораторная работа «Времяпролётный масс-спектрометр»

Настольное приложение (PySide6/PySide2 + Matplotlib) для курса «Физика ядра»:
входной тест, три задания на виртуальном времяпролётном масс-спектрометре и
PDF-отчёт для преподавателя. Архитектура — **MVP с пассивным видом**.

**Подробное описание для презентации:** [docs/MassLab_описание.md](docs/MassLab_описание.md)

## Возможности

- **Входной тест:** 10 случайных вопросов из банка (30), 4–6 вариантов, зачёт от 9/10,
  пересдача с новыми вопросами.
- **Задание 1:** запуск ионов, двухзарядные ионы, регулировка U и L, спектр, траектории,
  анимированная схема прибора, 5 контрольных вопросов на измерения.
- **Задание 2:** определение неизвестного элемента по калибрантам (время → масса → элемент)
  с указанием шага, на котором допущена ошибка.
- **Задание 3:** определение сплава по изотопному спектру.
- **Физика:** ширина пиков от разброса энергии ионов и детектора — у напряжения есть
  оптимум, показывается разрешение R; остаточный газ; изотопы.
- Тур-подсказки при первом входе в задание (повтор — «?»), методичка, подсказки после ошибок.
- Светлая и тёмная тема (кнопка ◐ в шапке, выбор действует до закрытия программы).
- Итог: время этапов, попытки, «ЗАЧТЕНО», **PDF-отчёт**, QR-код анкеты.
- Скрытый режим песочницы для преподавателя (поле без подписи на стартовом экране).
- **Ничего не сохраняется на диск**: каждый запуск — новая сессия; PDF — только по кнопке.

## Запуск из исходников

```bash
pip install -r requirements.txt     # Windows 10/11, Linux, macOS
python main.py
```

## Сборка exe (Windows 7 и новее)

Нужен Python 3.8 — последняя версия Python для Windows 7. Запустите `build_exe.bat`
(или вручную workflow *Actions → Build Windows exe*). Результат — папка `dist\MassLab`:
её целиком копируют на флешку и запускают `MassLab.exe`.

## Настройка

| Что | Где |
|---|---|
| Вопросы теста | `masslab/model/question_bank.py` |
| Ссылка на анкету (QR-код) | `masslab/config.py` → `FEEDBACK_FORM_URL` |
| Пароль песочницы (SHA-256) | `masslab/config.py` → `SANDBOX_PASSWORD_SHA256` |
| Параметры прибора | `masslab/model/physics.py` |
| Тексты тура / методички | `masslab/presenters/tour.py`, `masslab/model/theory.py` |
